## Install and run

Start with `bun install`, then run `bun run studio:dev` to open the local publishing studio against this workspace.

## Inspect the content tree

The homepage, docs pages, tags, and posts all resolve from the `content/` directory. Use that tree to understand how the publication is stitched together.

## Iterate locally first

This template assumes a local-first workflow. Review content in the studio, commit the results, and only then move toward deployment.
