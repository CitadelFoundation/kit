## Start locally

Run `bun install`, then use `bun run studio:dev` to launch the local studio host for this site.

## Publish with Git

The content tree under `content/` is the canonical source of truth. Change it through the studio or by editing files directly, then review and commit the result.

## Deploy when ready

This starter stays local-first. Add the Cloudflare Pages preset during `create` only if you want deployment scaffolding written into the generated site.
